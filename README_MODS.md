# Моди для Instruction: Don't Blink (IDB)

У головному меню натисни **Імпортувати мод** і вибери `.zip`. Усередині можуть лежати (усі файли необов'язкові):

| Файл | Що міняє |
|---|---|
| `monster.glb` | модель монстра (Y угору, обличчям до +Z, ~2.3 м заввишки, початок координат біля ніг) |
| `melon.glb` | кавун |
| `world.glb` | вулиця й квартира (вузли `door`, `fridgedoor`, `cab1`..`cab4`, `keyobj` мають зберегти імена) |
| `policecar.glb` | поліцейська машина (вузли `bar`, `barR`, `barB`, `trunk`) |
| `officer.glb` | поліцейський (вузли `hips`, `armL`, `armR`, `legL`, `legR`) |
| `menu_bg.jpg` | фон головного меню |
| `mod.json` | назва мода й числа, див. нижче |

Приклад `mod.json`:
```json
{
  "name": "Швидкий монстр",
  "watchSpeed": 0.8,
  "chaseSpeed": 1.6,
  "rushSpeed": 2.2,
  "keyTime": 45,
  "walkSpeed": 2.6,
  "limpSpeed": 1.5,
  "melons": 5
}
```
Кнопка **Вимкнути мод** у меню повертає оригінальну гру. Якщо мод зламаний, гра сама його вимкне.
