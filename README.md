# Instruction: Don't Blink (Android, 3D, горизонтально)

Мобільна 3D-гра: двір → квартира → монстр → кавун → ключ → 102 → свисток → поліція → "Wait, Chapter 2".

## Керування (екран горизонтальний)
- Джойстик зліва: вгору = вперед, вниз = назад.
- Свайп по правій частині екрана: огляд.
- **E** (з'являється поруч з предметами): зайти, холодильник, кавун, шафки, ключ, двері.
- **КИНУТИ** (затиснути, коли в руках кавун): кружечок зелений → жовтий → червоний. Відпустити на червоному = влучив. Тримати довше = кавун вибухає.
- **F**: телефон (після виходу з квартири), набрати 102.
- **C**: свисток (3 рази з паузами, коли монстр женеться).

## Збірка APK на GitHub
1. Створи репозиторій і запуш цей проєкт (усі файли в корені).
2. Вкладка **Actions** → "Build APK" → Run workflow (або просто пуш у main).
3. Коли збірка зелена, відкрий запуск і завантаж **Artifacts → IDB (файл IDB.apk)**.

## Моделі
Лежать у `app/src/main/assets/*.glb`. Скрипти, якими вони згенеровані, у `tools/` (`models.py`, `glbkit.py`, `monster.py`).
Монстр: твій `skinny_monster_2_1.glb`, спрощений з ~720 тис. до ~110 тис. трикутників (3,7 МБ).
